# 一人暮らし日記

就職して実家を出た日から30代前半までを「買う・買わない／高い・普通・安い」の選択だけで駆け抜ける人生シミュレーションです。新婚日記の前日譚です。企画と仕様は [一人暮らし日記 企画・設計書.md](./一人暮らし日記%20企画・設計書.md) にあります。

## いまの状態（フェーズ5：新婚日記との連携）

設計書の12イベント、ランダムイベント、所有物のリスク判定がすべて入り、1周通して遊べます。演出とリザルトも仕上がり、5言語（日本語・English・繁體中文・Español・한국어）で遊べます。英語はアメリカ・シンガポール・フィリピン・カナダ・オーストラリアを開始設定で選べ（最初はアメリカ。Issue #15）、スペイン語はメキシコです。ほかの言語は国のプロファイルがそろうまで日本のままです。

- 開始設定：性別、一人暮らしを始める年齢（22〜28歳）、貯金（0〜300万円）、年収（初期値は年齢の中央値）。ランダム・全部おまかせ
- ライフイベント：部屋探し、家電・家具（寿命で買い替え）、食生活・付き合い・趣味（3年ごとに見直し）、部屋の更新（2年ごと。更新か引っ越し）、自己投資（24歳から3年ごと、最大3回）、車（25歳から、買い替えあり）、旅行（2年ごと）、恋人との交際、婚活（28歳以降、恋人がいない年に2年ごと）、これからの暮らし（分岐）
- 毎年の判定：昇進（基本8%）と病気・ケガ（基本5%）を単独で判定し、充実度・食生活・スクールの補正が効く
- ランダムイベント（毎年20%）：転職の誘い、ボーナスカット、臨時収入、友人の結婚式
- 所有物のリスク：家電の故障、車の故障、隣人トラブル（引っ越すか我慢するか）
- 演出：イベントごとのイラスト（インライン SVG）、選択に応じた日記の文、年末の収支の表示
- リザルト：ランク（純資産。S 800／A 500／B 300／C 0 万円）、エンディング（結婚／ひとり × 充実度の6種類＋家計破綻）、称号9つ、実績12個、人生年表、生涯支出の内訳、「全部普通」との差額、シェア用の画像カード
- 新婚日記へ続く：結婚エンドでは大きく、ひとりエンドでは小さくリンクを出す。性別・年齢・貯金・年収・車を `https://newlywed-diary.nacn.app/<言語>/?from=solo&d=<base64url>` で渡す（新婚日記側は `parseHandoff` で読み、引き継いだ開始設定から始める）
- 国プロファイル：`data/countries.json` に、言語ごとに選べる国（先頭が既定）と、プロファイルのそろった国を書く。数値は `data/profiles/<国>.json`、文は `data/profiles/<国>/<言語>.json`。いまそろっているのは日本・アメリカ・シンガポール・フィリピン・カナダ・オーストラリア・メキシコ。数値の出典は設計書の「国プロファイル」
- タイトル画面から続編の新婚日記へ、新婚日記のタイトル画面から一人暮らし日記へリンクする

`npm run simulate` の結果（22歳・貯金100万円・年収250万円、方針ごとに1,000回）です。

### 新婚日記から変えたところ

- 5言語の訳は、新婚日記の同じ言語の訳に用語と言い回しをそろえた。プライバシーポリシーは、新婚日記と同じく言語ごとの節（英語の米国居住者向け、繁體中文の個人資料、韓国語のクッキー、スペイン語の連絡先と権利）を残した
- サイトの URL は `https://solo-living-diary.nacn.app/`。名前は English「Solo Living Diary」、繁體中文「獨居日記」、Español「Diario de vida independiente」、한국어「자취일기」
- 保存のキーは `solo-living-diary-*`
- イラストは、一人暮らし日記でも使うもの（部屋・旅行・車・本・グラフ）を残し、ほかのイベントのぶんを足した

### v1 のあとに検討すること

設計書の「未決事項」（18歳開始、ペット、懐かし日記との連携、金額の確認）。

## 開発

```bash
npm test                 # エンジンのテスト
npm run simulate [回数] [国]  # 方針ごとの自動プレイ（国は jp・us・sg・ph・ca・au・mx。既定は jp）
npm run check:i18n       # 翻訳のキーと差し込みが日本語版とそろっているかの確認
python3 build.py         # src・i18n を変えたら書き出して、書き出したファイルもコミットする
node tools/make_og.cjs   # OGP 画像（Playwright が必要）
```

データを `fetch` で読むので、ファイルを直接開くのではなく、静的サーバーで配信してください。

```bash
python3 -m http.server 8000
# http://localhost:8000/ja/ などを開く（http://localhost:8000/ は言語を選ぶページ）
```
