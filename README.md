# 一人暮らし日記

就職して実家を出た日から30代前半までを「買う・買わない／高い・普通・安い」の選択だけで駆け抜ける人生シミュレーションです。新婚日記の前日譚です。企画と仕様は [一人暮らし日記 企画・設計書.md](./一人暮らし日記%20企画・設計書.md) にあります。

## いまの状態（フェーズ0：複製と整理）

[新婚日記](https://github.com/NaokiIshimura/newlywed-diary) のリポジトリを複製し、新婚日記にしかないもの（結婚式・子ども・教育・マイホーム・働き方・介護などのイベント、文、称号、実績、パートナー）を外しました。ライフイベントのない状態で、開始から35歳まで1周回ります。

- 開始設定：性別、一人暮らしを始める年齢（22〜28歳）、貯金（0〜300万円）、年収（初期値は年齢の中央値）。ランダム・全部おまかせ
- 毎年の収支：手取り（年収×0.78、年齢の中央値の比で伸びる）− 生活費（年45万円、毎年1.25%上昇）− 家賃 − 食費 − 利息
  - 家賃（年80万円）と食費（年45万円）は、部屋探しと食生活のイベントが入るまでの仮の固定額（`data/profiles/jp.json` の `rent`・`food`）
- ランダムイベント（毎年30%）：昇進、転職の誘い、病気・ケガ、ボーナスカット、臨時収入。新婚日記の抽選の仕組みのまま（設計書の「昇進と病気・ケガの単独判定」はフェーズ2で入れる）
- 終了：35歳で終了、−300万円を下回ると家計破綻エンド。ランクは S 600／A 400／B 200／C 0 万円
- 称号（見栄っ張り・節約の達人・堅実派・バランス派）と実績（貯金の鬼・どん底を知る・借金ゼロ・思わぬ大金・転職成功）は、設計書のうち今の仕組みで判定できるものだけ
- そのまま使っている新婚日記の部品：日記と年末の収支の表示、リザルト、シェア用の画像カード、エンディング図鑑、設定、途中保存、遊び方・プライバシーポリシーのページ、Cookie の同意

ライフイベントがないので、`npm run simulate` の結果はどの方針でも同じです（22歳・貯金100万円・年収250万円で、純資産の中央値は約1,370万円）。

### 新婚日記から変えたところ

- 言語は日本語だけ（`js/i18n.js`・`build.py`・`tools/` の `LANGS`）。ほかの4言語はフェーズ4で、新婚日記の訳を参考に足す
- サイトの URL は `https://solo-living-diary.nacn.app/`（仮。リポジトリ名に合わせた）
- 保存のキーは `solo-living-diary-*`
- イラストは、一人暮らし日記でも使うもの（部屋・旅行・車・本・グラフ）だけ残した

### まだ決めていないこと

- 名前とサブドメイン（英語名を含む）。変えるときは `build.py` の `SITE`、`src/root.html`、`robots.txt`、プライバシーポリシーを直す
- Google アナリティクスの測定 ID。いまは新婚日記と同じ ID（`src/game.html`・`src/page.html`・`src/root.html`・`src/404.html`）

## 開発

```bash
npm test                 # エンジンのテスト
npm run simulate [回数]  # 方針ごとの自動プレイ
npm run check:i18n       # 翻訳のキーの確認（いまは日本語だけ）
python3 build.py         # src・i18n を変えたら書き出して、書き出したファイルもコミットする
node tools/make_og.cjs   # OGP 画像（Playwright が必要）
```

データを `fetch` で読むので、ファイルを直接開くのではなく、静的サーバーで配信してください。

```bash
python3 -m http.server 8000
# http://localhost:8000/ja/ を開く
```
