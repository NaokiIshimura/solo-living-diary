# 一人暮らし日記

就職して実家を出た日から30代前半までを「買う・買わない／高い・普通・安い」の選択だけで駆け抜ける人生シミュレーションです。新婚日記の前日譚です。企画と仕様は [一人暮らし日記 企画・設計書.md](./一人暮らし日記%20企画・設計書.md) にあります。

## いまの状態（フェーズ1：プロトタイプ）

開始設定から「これからの暮らし」の分岐まで、1周通して遊べます。テキストだけで、イラストはまだありません。

- 開始設定：性別、一人暮らしを始める年齢（22〜28歳）、貯金（0〜300万円）、年収（初期値は年齢の中央値）。ランダム・全部おまかせ
- ライフイベント：部屋探し（2年ごとに更新料）、食生活と付き合い（3年ごとに見直し）、恋人との交際、これからの暮らし（分岐）
- 充実度：0〜100、開始50。毎年、選んだものの値の合計 − 3。充実（70以上）・ふつう・無気力（30以下）で、出会い・別れ・昇進・年収の伸びに効く
- 出会いと別れ：恋人がいない年は 10% ＋ 付き合い ＋ 充実度の補正で出会い、交際中は交際費に応じた確率で別れる
- 分岐：恋人がいて30歳以上・交際2年以上か、35歳で発生。結婚エンド／ひとりエンド × 充実度の6種類と、家計破綻エンド（−300万円）
- 毎年の収支：手取り（年収×0.78）− 生活費 − 家賃 − 食費 − 付き合い − 交際費 − 利息
- ランダムイベント（毎年30%）：昇進、転職の誘い、病気・ケガ、ボーナスカット、臨時収入（新婚日記の抽選の仕組みのまま。単独判定はフェーズ2）
- ランク：S 600／A 400／B 200／C 0 万円。称号4つ・実績5つ

フェーズ2で入れるもの：家電・家具、部屋の更新、趣味・推し活、自己投資、車、旅行、婚活、所有物のリスク判定、昇進と病気・ケガの単独判定、バランス調整。

`npm run simulate` の結果（22歳・貯金100万円・年収250万円、方針ごとに500回）です。趣味や車などの出費がまだないので、「全部安い・やらない」が強すぎる状態です。

| 方針 | 純資産の中央値 | 充実度 | 結婚 |
| --- | --- | --- | --- |
| 全部普通 | 約770万円 | 39 | 74% |
| 全部安い | 約1,360万円 | 0 | 26% |
| 全部やらない | 約1,370万円 | 0 | 1% |
| 全部高い | 破綻（98%） | 66 | 1% |
| 要所だけ高い（付き合いだけ高い） | 約350万円 | 59 | 85% |

### 新婚日記から変えたところ

- 言語は日本語だけ（`js/i18n.js`・`build.py`・`tools/` の `LANGS`）。ほかの4言語はフェーズ4で、新婚日記の訳を参考に足す
- サイトの URL は `https://solo-living-diary.nacn.app/`（仮。リポジトリ名に合わせた）
- 保存のキーは `solo-living-diary-*`
- イラストは、一人暮らし日記でも使うもの（部屋・旅行・車・本・グラフ）だけ残した

### まだ決めていないこと

- 名前とサブドメイン（英語名を含む）。変えるときは `build.py` の `SITE`、`src/root.html`、`robots.txt`、プライバシーポリシーを直す
- Google アナリティクスの測定 ID。いまは新婚日記と同じ ID（`src/game.html`・`src/page.html`・`src/root.html`・`src/404.html`）

## 開発

```bash
npm test                 # エンジンのテスト
npm run simulate [回数]  # 方針ごとの自動プレイ
npm run check:i18n       # 翻訳のキーの確認（いまは日本語だけ）
python3 build.py         # src・i18n を変えたら書き出して、書き出したファイルもコミットする
node tools/make_og.cjs   # OGP 画像（Playwright が必要）
```

データを `fetch` で読むので、ファイルを直接開くのではなく、静的サーバーで配信してください。

```bash
python3 -m http.server 8000
# http://localhost:8000/ja/ を開く
```
