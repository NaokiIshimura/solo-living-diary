# 一人暮らし日記

就職して実家を出た日から30代前半までを「買う・買わない／高い・普通・安い」の選択だけで駆け抜ける人生シミュレーションです。新婚日記の前日譚です。企画と仕様は [一人暮らし日記 企画・設計書.md](./一人暮らし日記%20企画・設計書.md) にあります。

## いまの状態（フェーズ5：新婚日記との連携）

設計書の12イベント、ランダムイベント、所有物のリスク判定がすべて入り、1周通して遊べます。演出とリザルトも仕上がり、5言語（日本語・English・繁體中文・Español・한국어）で遊べます。英語はアメリカ・シンガポール・フィリピン・カナダ・オーストラリアを開始設定で選べ（最初はアメリカ。Issue #15）、スペイン語はメキシコ、繁體中文は台湾、韓国語は韓国、日本語は日本です。

- 開始設定：性別、一人暮らしを始める年齢（22〜28歳）、貯金（0〜300万円）、年収（初期値は年齢の中央値）。ランダム・全部おまかせ
- ライフイベント：部屋探し、家電・家具（寿命で買い替え）、食生活・付き合い・趣味（3年ごとに見直し）、部屋の更新（2年ごと。更新か引っ越し）、自己投資（24歳から3年ごと、最大3回）、車（25歳から、買い替えあり）、旅行（2年ごと）、恋人との交際、婚活（28歳以降、恋人がいない年に2年ごと）、これからの暮らし（分岐）
- 毎年の判定：昇進（基本8%）と病気・ケガ（基本5%）を単独で判定し、充実度・食生活・スクールの補正が効く
- ランダムイベント（毎年20%）：転職の誘い、ボーナスカット、臨時収入、友人の結婚式
- 所有物のリスク：家電の故障、車の故障、隣人トラブル（引っ越すか我慢するか）
- 演出：イベントごとのイラスト（インライン SVG）、選択に応じた日記の文、年末の収支の表示
- リザルト：ランク（純資産。S 800／A 500／B 300／C 0 万円）、エンディング（結婚／ひとり × 充実度の6種類＋家計破綻）、称号9つ、実績12個、人生年表、生涯支出の内訳、「全部普通」との差額、シェア用の画像カード
- 新婚日記へ続く：結婚エンドでは大きく、ひとりエンドでは小さくリンクを出す。性別・年齢・貯金・年収・車を `https://newlywed-diary.nacn.app/<言語>/?from=solo&d=<base64url>` で渡す（新婚日記側は `parseHandoff` で読み、引き継いだ開始設定から始める）
- 国プロファイル：`data/countries.json` に、言語ごとに選べる国（先頭が既定）と、プロファイルのそろった国を書く。数値は `data/profiles/<国>.json`、文は `data/profiles/<国>/<言語>.json`。いまそろっているのは日本・アメリカ・シンガポール・フィリピン・カナダ・オーストラリア・メキシコ・台湾・韓国。数値の出典は設計書の「国プロファイル」
- タイトル画面から続編の新婚日記へ、新婚日記のタイトル画面から一人暮らし日記へリンクする
- 結果画面の共通部品（series-kit）：シェアの下・「もう一度」の上に、ルートの `series-kit.js` が連続日数（2日以上のとき）と「次に遊ぶ」のカード2枚（1枚目は日記シリーズのほかの作品、2枚目はほかのゲーム。日ごとに入れ替わる）を出す。シェア（画像カード）と新婚日記への引き継ぎのリンクはゲームのものを使い（`share: false`）、ベストの純資産はエンディング図鑑に出しているので kit のベストは出さない（`best: false`、点数も渡さない）。記録は localStorage の `nacn-kit:solo-living-diary`。`series-kit.js` は claude-skills の `series-kit` スキルの写しなので**直接は編集せず**、スキルの元の版を直して `scripts/build_kit.py --copy` で写し直し、`build.py` の `ASSET_VER` を新しくして書き出し直す。呼び出しは `js/app.js` の `showResult()`

`npm run simulate` の結果（22歳・貯金100万円・年収250万円、方針ごとに1,000回）です。

調整の考え方と変えた値は、設計書の「バランスの目標」と「自動プレイの結果」にあります。

### 新婚日記から変えたところ

- 5言語の訳は、新婚日記の同じ言語の訳に用語と言い回しをそろえた。プライバシーポリシーは、新婚日記と同じく言語ごとの節（英語の米国居住者向け、繁體中文の個人資料、韓国語のクッキー、スペイン語の連絡先と権利）を残した
- サイトの URL は `https://solo-living-diary.nacn.app/`。名前は English「Solo Living Diary」、繁體中文「獨居日記」、Español「Diario de vida independiente」、한국어「자취일기」
- 保存のキーは `solo-living-diary-*`
- イラストは、一人暮らし日記でも使うもの（部屋・旅行・車・本・グラフ）を残し、ほかのイベントのぶんを足した

## 開発

```bash
npm test                 # エンジンのテスト
npm run simulate [回数] [国]  # 方針ごとの自動プレイ（国は jp・us・sg・ph・ca・au・mx・tw・kr。既定は jp）
npm run check:i18n       # 翻訳のキーと差し込みが日本語版とそろっているかの確認
python3 build.py         # src・i18n を変えたら書き出して、書き出したファイルもコミットする
node tools/make_og.cjs   # OGP 画像（Playwright が必要）
```

データを `fetch` で読むので、ファイルを直接開くのではなく、静的サーバーで配信してください。ページの間のリンクは公開先（Cloudflare Pages）の正規URLと同じく `.html` を付けない（`howto`・`privacy`）ので、`.html` を外した URL も配信する `tools/serve.py` を使います（新婚日記と同じもの）。

```bash
python3 tools/serve.py 8000
# http://localhost:8000/ja/ などを開く（http://localhost:8000/ は言語を選ぶページ）
```

## 公開（Cloudflare Pages）

- 公開先は `https://solo-living-diary.nacn.app/`
- `solo-living-diary.pages.dev` で開かれたら、`functions/_middleware.js`（Pages Functions）が `https://solo-living-diary.nacn.app/` の同じパスへ 301 で転送する。プレビュー（`<hash>.solo-living-diary.pages.dev` やブランチの別名）は確認できるよう転送しない
- Google アナリティクス：測定ID `G-NH0RLHNX0K`（nacn.app のゲームで共通）。全ページの head（`src/*.html` の「<!-- Google Analytics -->」）に入り、本番（`solo-living-diary.nacn.app`）で開いたときだけ gtag.js を読み込む。プレビュー・pages.dev・手元では計測しない（`gtag()` は定義されるので、イベントの呼び出しはエラーにならない）。ゲームから送るイベントは次のとおり（`js/app.js` の `track()`）

  | イベント | いつ | パラメータ |
  |---|---|---|
  | `game_start` | 開始設定で「はじめる」か「おまかせ」を押したとき | `lang`・`country`（`jp` など）・`mode`（`custom`・`omakase`）・`start_age`・`gender` |
  | `game_end` | 結果が出たとき（1回のプレイで1回） | `ending`（エンディングのキー。`married`・`single_low`・`bankrupt` など）・`rank`・`title`（称号のキー）・`end_age`・`achievements`（実績の数）・`lang`・`country` |
  | `share` | 結果のシェアのボタンを押したとき | `method`（`x`・`native`・`download`）・`content_type: 'result'` |
  | `retry` | 結果の「もう一度」を押したとき | `lang` |
  | `select_content` | 新婚日記・ポータルなど、ほかの nacn.app のサイトへのリンクを押したとき | `content_type: 'game'`・`item_id`（リンク先のサブドメイン。ポータルは `portal`） |
  | `select_content`（結果画面） | 結果画面の「次に遊ぶ」のカードを押したとき（series-kit が送る。リンクに `utm_source=solo-living-diary&utm_medium=next_card&utm_campaign=series_kit` を付ける） | `content_type: 'game'`・`item_id`（リンク先のゲーム）・`from: 'solo-living-diary'` |
- Google AdSense（パブリッシャーID `ca-pub-3999397576072658`）のタグを、404 を除く全ページ（`src/game.html`・`src/page.html`・`src/root.html`）の head に直接書いている（審査でタグの有無を確認されるため。GA と違ってどのホストでも読み込む）。ゲームの画面では、広告ブロッカーなどで読み込めなければ広告枠を隠す。広告枠を出すのはタイトル画面（`#ad-box`）と結果画面（series-kit の `adSlot`）だけで、`js/app.js` の `AD_SLOT` に広告ユニットIDを入れるまでは、どちらの枠も出さない（いまは空）。`ads.txt` はダイエット日記・筋トレ日記と同じ内容で、`solo-living-diary.nacn.app/ads.txt` でも返すために置いている（AdSense の審査と `ads.txt` の確認はルートドメインの `nacn.app` で行われるので、ポータルの `https://nacn.app/ads.txt` が正）。広告の配信はプライバシーポリシー（`src/pages/<言語>/privacy.html`）の「広告の配信について」に書いている。Cookie の同意のバナー（`i18n/<言語>.json` の `site.consent.text`）も広告ありの文言にしている
- 日記シリーズは人生の順番（ノスタルジア日記 → 一人暮らし日記 → 新婚日記）でつなぐ。タイトル画面の下に、前日譚（`https://nostalgia-diary.nacn.app/<言語>/`、文言は言語データの `title.prequel`）と続編（新婚日記、`title.sequel`）へのリンクを置く。結果画面からは新婚日記へ引き継ぎデータ付きで続く。ノスタルジア日記のエンディングからは、この一人暮らし日記へリンクしている
